# Legacy exploration

Earlier notebooks and scripts from the development of the crossover operator: the original Nguyen and Feynman
notebooks, Optuna tuning, the pretrained pair scorer (`pretrain_selector.py`, used only by the `pretrained*`
development arms) and older analysis and queue scripts. None of them is part of the pipeline that produced the
paper's results (see `../README.md`), and they are not maintained. Most import `main` from the repository root,
so run them from there, e.g. `python legacy/analyze_selectors.py`.
