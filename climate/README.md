# Microclimate application (not part of the GP-SR-RLC benchmark paper)

Scripts and data for the symbolic-regression models of monsoon microclimate at Kanha Shanti Vanam, which use
the GP in `../main.py`. They are kept here for that study and are not used by the crossover paper.

Run them from this folder (`cd climate; python climate.py`); they read `monsoon.csv` / `monsoon_daily.csv`
here and import `main` from the repository root. Extra packages: scikit-learn, seaborn and matplotlib.
